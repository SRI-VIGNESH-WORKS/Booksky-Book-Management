# Booksky - Book Management App

Booksky is a simple and interactive book management web application built using HTML, CSS, and JavaScript. It provides a user-friendly interface for displaying book details and allows users to add and delete books dynamically.

This project was developed to practice front-end web development concepts, including DOM manipulation, event handling, and CSS styling.

## About the Project

Booksky allows users to maintain a collection of books by entering the book title, author name, and a short description. The application features a popup form for adding books and a simple interface for displaying and managing book entries.

## Features

* **Add Books:** Add new books by entering the title, author, and description.
* **Display Books:** View book details in individual book cards.
* **Delete Books:** Remove books from the collection.
* **Interactive Popup:** Open and close a popup form to add book details.
* **Simple User Interface:** Clean design with a pink-and-black color scheme.
* **Dynamic Content:** Update the displayed book collection using JavaScript.

## Technologies Used

* **HTML5** - Structures the web page and form.
* **CSS3** - Styles the layout, book cards, buttons, and popup.
* **JavaScript** - Handles user interactions and dynamic content management.

## Getting Started

Follow these instructions to run the project on your local machine.

### Prerequisites

* A modern web browser such as Google Chrome.
* A code editor such as Visual Studio Code.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/SRI-VIGNESH-WORKS/Booksky-Project.git
```

**2. Navigate to the project directory**

```bash
cd Booksky-Project
```

**3. Run the application**

Open the `index.html` file in your web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension to run it locally.

## How to Use

1. Open the Booksky application in your browser.
2. Click the plus (+) button to open the Add Book popup.
3. Enter the book title, author name, and a short description.
4. Click the ADD button to add the book to the collection.
5. Click the Delete button on a book card to remove it.
